## References

For every reference, record the actual file/URL, which aspect it guides, and permission status if its bytes will be reused. Consider visual style, character silhouette/proportions, wardrobe, materials, props, environments, typography, camera, motion, editing rhythm, voice performance, sound and caption behavior.

## Missing capabilities

Record actual access gaps: web research, image generation, voice provider, imported models, renderer runtime, or analytics. A reference or plan is not evidence that a capability is configured.
