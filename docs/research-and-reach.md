# Research and audience viability

## Evidence first

The topic scout gathers candidate angles; the researcher then investigates the selected event or question. Preserve source URLs, publication and event dates, access timestamps, author/publisher, exact relevant claims, and independence groups. Prefer original investigations, scientific papers, official archives, named interviews and credible contemporaneous reporting. Match the source type to the claim being made.

A page repeating a wire report is not an independent confirmation. A first-person report can establish what someone said they experienced without proving a paranormal cause. A scientific paper's finding may apply only to its sampled conditions. Preserve limitations alongside the claim so the writer can phrase it accurately.

Record the latest status of unresolved stories. Historic evidence can be old, but the question “is this still unsolved?” needs a current check. `research.freshness_days` controls how recently research/policy sources were accessed. The validator checks access timestamps; the researcher must actually revisit the source and verify the relevant conclusion.

## What “viability” means here

StoryForge ranks the usefulness of producing a topic with the evidence available. It does not predict a guaranteed view count or fabricate a probability of going viral. A niche with sparse data may still justify a small, clearly labelled experiment.

| Signal | How to gather it | What it can support | Important limit |
| --- | --- | --- | --- |
| Channel evidence | Authorized YouTube Studio export or supplied analytics | Relative fit with this channel's audience | Historical results do not ensure the next result |
| Studio Trends | User-authorized access or exported observations | Audience searches and content-gap ideas | Features and availability vary |
| Public comparable videos | Open actual pages and record upload date, views and format | Observed response to related treatments | Channel size, age, promotion and distribution are confounders |
| Google Trends | Save query, search type, region and date window | Relative changes in search interest | The index is not absolute search volume |
| Search results/community questions | Read the actual question and context | A possible unmet explanation or angle | Anecdotes are not representative audience measurement |
| Production fit | Asset breakdown and render proof | Whether a compelling version is feasible | Ease of production is not audience demand |

YouTube's Trends feature provides idea and content-gap signals, with some insights limited by country, language or device. Use what the account actually exposes and record unavailable fields as unknown. [YouTube Trends documentation](https://support.google.com/youtube/answer/11962757).

Google Trends reports relative, normalized interest for the chosen geography and period; its 0–100 scale does not tell you an absolute number of searches. Save the comparison settings and interpret isolated low-volume spikes cautiously. [Google Trends data FAQ](https://support.google.com/trends/answer/4365533).

## Comparable-video protocol

Choose a small, relevant comparison set rather than cherry-picking a viral outlier. Separate Shorts from long-form. Record topic, angle, date, runtime, visible view count, channel context, title promise, opening treatment and source URL. If a value is hidden or inaccessible, mark it unavailable. Do not infer private retention or revenue from public counts.

An age-normalized count can be a rough descriptive measure only when the underlying values are observed. Label how it was calculated and why the comparison may be distorted. Avoid implying a large channel's distribution is available to a new channel. Compare recent and older examples separately when a news cycle could explain attention.

## Prioritization rubric

Use a transparent subjective 0–5 assessment for `demand`, `competition_gap`, `hook`, `visual_potential`, `source_quality`, and `production_fit`. Use null for an unmeasured dimension. Give a short explanation and evidence reference for each assigned score. Do not hide unknown values by averaging them as zero.

The recommendation is `go`, `revise`, or `reject`, with `low`, `medium`, or `high` confidence. Medium/high confidence needs concrete evidence. The producer should describe the decision in words: for example, “credible evidence and a distinct visual explanation; demand is still uncertain, so this is a low-cost experiment.”

If you compute an overall score, state the weights, missing-data handling, and sensitivity to changing the assumptions. Treat it as a comparison aid. A score of 82 is not an 82% chance of success.

## Post-publication feedback

Use comparable windows and the channel's own baseline. For Shorts, inspect the available stayed-to-watch/engaged-view metrics, watch time, average view duration, percentage viewed, and the retention shape. For long-form, include thumbnail impressions/click-through context, retention, viewing duration and traffic sources. Preserve the metric definitions supplied by the current export: YouTube changes views and engagement reporting, so historical metrics may not be directly comparable. [Content performance definitions](https://support.google.com/youtubecreatorstudio/answer/12220281).

Retention reports can identify specific moments where viewers leave, rewatch, or continue. Inspect the corresponding narration and visual event before proposing a cause; a chart alone does not establish why viewers behaved that way. [Audience-retention documentation](https://support.google.com/youtube/answer/9314415).

Write a short learning record: observation, plausible explanation, competing explanation, confidence, next production change, and how to evaluate it. Keep the analyst separate from the writer so the loop can challenge established habits.
